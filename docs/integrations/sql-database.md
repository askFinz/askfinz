# SQL database search without writing queries

Bring any SQL database into askFinz Knowledge so every table and record is searchable without writing queries. Coming to askFinz soon.

**Canonical page:** [https://askfinz.com/integrations/sql-database](https://askfinz.com/integrations/sql-database)

## Key points

### Ask a question instead of writing a query

Ask "which accounts churned after a support escalation" and get an answer drawn from the tables you exposed, with the rows it used named so an analyst can verify them.

### Search the text columns nobody indexes

Descriptions, reason codes, free-text notes and comment tables hold the explanation behind a status change. Those are matched by meaning rather than exact wording, which is exactly what LIKE '%...%' cannot do.

### Expose a defined slice, not the whole schema

ONE RECORD’S FIELDS WHAT IT BECOMES WHAT THAT LETS YOU ASK Name, title, reference the short columns Text you can match by meaning, not spelling “the renewal we agreed in March” Notes, descriptions, comments the long columns Text you can quote answers cite the record “why was this one discounted?”…

### What crosses, and what stays in the database

Comes in Read rows from the tables and views you list, on a schedule you set.

### What you will be granting

A read-only database user, scoped to the tables and views you name — the same thing you would give a reporting tool, and nothing that can change data.
