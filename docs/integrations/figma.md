## Key points

### Find the file by describing the screen

Search for "the checkout step with the saved-card toggle" rather than guessing which project it was filed under.

### Recover why a design changed

Comment threads are where the trade-off was made and where a stakeholder's objection was resolved. Connected, those answer questions directly, with the file and frame named.

### Keep design decisions searchable next to the spec

The design lives in Figma and the requirement lives in a ticket or a doc. Asking one question across all three is the point; the answer cites each source so you can open it.

### What crosses, and what stays in Figma

file, page and frame names, text layers, descriptions and comment threads from the projects you select.

### What you will be granting

Read-only access to the team projects you choose, matching what the connecting member can already open in Figma.
