# Asana integration: search tasks and projects

Bring Asana into askFinz Knowledge so every task, project, and goal is searchable in plain language. Coming to askFinz soon.

**Canonical page:** [https://askfinz.com/integrations/asana](https://askfinz.com/integrations/asana)

## Key points

### Reuse a completed project instead of rebuilding it

Ask how the last launch was sequenced and get the answer from the project that ran it, with the tasks named — including the ones that slipped and why.

### Find the task where a decision was actually made

Decisions get made in task comments and then vanish under a completed checkbox. Comments are searched by meaning, so you can find the thread without remembering whose task it was.

### Answer status questions without chasing anyone

Portfolio and goal descriptions carry the framing that a task list does not. Connected, "what is this workstream for" is answerable from the material the team already wrote.

### What crosses, and what stays in Asana

Comes in Read task names, descriptions, comments, project briefs and goals from the projects you select.

### What you will be granting

Read-only access to the workspaces and projects you choose, limited to what the connecting member can already see in Asana.
