# Airtable integration: search every base

Bring Airtable into askFinz Knowledge so every base, table, and record is searchable and usable in plain language. Coming to askFinz soon.

**Canonical page:** [https://askfinz.com/integrations/airtable](https://askfinz.com/integrations/airtable)

## Key points

### Ask across bases without building a view

Today, answering "which vendors did we shortlist and why" means opening the right base, remembering the right view, and reading. Connected, you ask the question once and the answer draws on whichever base holds it, naming the record so you can open it.

### Read the long-text fields, not just the labels

Notes, briefs and comment fields carry the reasoning that a status column cannot. Those get matched by meaning, so a search for "the supplier we dropped over lead times" can find a record that never uses the word "lead time".

### What crosses, and what stays in Airtable

Comes in Read field values and long-text content from the bases and tables you select.

### What you will be granting

Read-only access to the specific bases you choose, using the same permissions your own Airtable account already has — no more reach than you have today.
