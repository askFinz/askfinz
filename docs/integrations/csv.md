## Key points

### Ask a dataset a question in words

Upload the file and ask what you actually want to know — "which regions complained about delivery times" — rather than translating it into a filter, a pivot and a formula first.

### Search the sentences inside the columns

Free-text columns are where the useful detail hides: comments, reasons, notes. Those are matched by meaning, so a row can come back even when it does not repeat your wording.

### Use it beside your other work
