## Key points

### Search by content, not by folder structure

Describe what was in the document and get it, whichever nested folder it ended up in.

### Bring an archived project back into use

Old work becomes answerable instead of merely stored, so the proposal you wrote for a similar client is a question away rather than an archaeology exercise. Team folders and your own folders can be connected separately, so an archive can be searchable to everyone while your drafts stay yours.

### Keep shared folders shared exactly as before

### What crosses, and what stays in Dropbox

### What you will be granting
