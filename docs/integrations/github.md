# GitHub integration: search repos, issues, PRs

Bring GitHub into askFinz Knowledge so repos, pull requests, issues, and docs are searchable in Chat and Research. Coming to askFinz soon.

**Canonical page:** [https://askfinz.com/integrations/github](https://askfinz.com/integrations/github)

## Key points

### Ask why the code looks like this

Point a question at a file or a subsystem and get the discussion that produced it — the review comment that changed the approach, the issue that set the constraint — with each one linked so you can read it in full.

### Trace a decision from issue to merged pull request

Issue, branch, review, merge: the chain exists, but following it means six tabs. Connected, the chain is one answer, and it survives the person who wrote it leaving.

### Search the docs that live beside the code

READMEs, /docs folders, ADRs and wiki pages are searched in the same breath as the discussion, so an onboarding question does not depend on knowing which of those three places the answer was written in.

### What crosses, and what stays in GitHub

Comes in Read code, READMEs, issues, pull requests and reviews from the repositories you select.

### What you will be granting

Read-only access to the repositories you tick, and nothing else in the organisation — the standard app install, which an owner can revoke in one click.
