# GitLab integration: search issues and wikis

Bring GitLab into askFinz Knowledge so merge requests, issues, and wikis are searchable in Chat and Research. Coming to askFinz soon.

**Canonical page:** [https://askfinz.com/integrations/gitlab](https://askfinz.com/integrations/gitlab)

## Key points

### Ask why a change was made the way it was

The review thread on a merge request is the closest thing most teams have to design documentation. Connected, it answers questions directly, with the merge request linked so you can read the rest.

### Search group and project wikis with the issues

Wikis go stale because nobody finds them. Searching them in the same breath as issues and merge requests means the runbook surfaces when someone asks the question it answers, not only when they think to browse.

### Follow an incident from issue to fix

Issue, branch, merge request, release notes. That chain is answerable as one question rather than four searches, and it stays answerable after the people involved move on.

### What crosses, and what stays in GitLab

Comes in Read issues, merge requests, comments, wikis and repository docs from the projects you select.

### What you will be granting

Read-only access scoped to the groups and projects you choose, using a token that cannot write anything back.
