## Key points

### A studio for the rendering, not just the prompting

The fun part of generative tools is the first render. The hard part is everything after — masking, inpainting, trimming, captioning, organising.

### Render an image, generate a 4-second clip, layer the edits

A scripted walk-through — prompt, image render, model swap, video render appearing, a new generative layer added to the panel. Try the real thing at create.askfinz.ai.
