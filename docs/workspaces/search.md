# AI search engine with sources and citations

askFinz's own search engine, built so a person, an agent or a model can ask the same question and each get back something they can use.

## Key points

### A search engine for humans, agents and LLMs

Ask in plain language and get results grouped by meaning — not just keywords. A human gets cards with confidence bars; an agent gets a structured response it can pass downstream; an LLM gets passages shaped for in-context grounding.

### The query, in motion

Query bar, streaming results, confidence bars and an agent-cited badge. The real surface lives at search.askfinz.ai.

### What ships today

Search is live in production. The features below are working today — not roadmap promises.

### Where Search runs

One account, many surfaces. Search is reachable from the surfaces lit below.

### Millions of pages. Answered while you let go of the key

Search runs across the whole live index, and it doesn't wait for a nightly rebuild to know something. The figures below come straight from the engine as it's running — not from a slide.

### Good answers need someone to have read the page first

A search engine is only as good as what it has actually read. askFinz reads the web continuously — including documents, app-built pages and the awkward corners most crawlers skip — and files what it finds the moment it sees it.

### Everything Search shows is grounded in a real-time index

Behind the scenes, a web crawler and the browser extension read pages across the web, and an indexer turns them into searchable knowledge the moment they're seen — including modern apps and bot-walled sites others can't reach.
