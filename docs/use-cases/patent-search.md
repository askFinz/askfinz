## Frequently asked

### Can askFinz search patents by what an invention does?

Yes. Filings are searchable by function and description rather than by title wording alone, so a prior-art search can start from plain language instead of guessing the exact phrasing an examiner used.

### Does it cover multiple patent offices?

Yes. The index reads granted patents and published applications from patent offices directly, so a result links back to the office's own publication rather than a secondary summary.

### Is this a substitute for a patent attorney or a formal freedom-to-operate opinion?

No. askFinz surfaces the prior art and the filings for you to read — it doesn't file anything or give a legal opinion on patentability or infringement.
