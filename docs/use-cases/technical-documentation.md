## Frequently asked

### Can askFinz draft documentation from my actual codebase?

Yes. The Code workspace's assistant reads your project and can answer questions about what it actually does, which you can turn into a first draft grounded in the real code rather than an assumption about it.

### Can it check how similar problems have been documented or answered elsewhere?

Yes. Search reaches public question-and-answer threads and documentation, so you can see how a similar problem has been explained before drafting your own version.

### Does it keep old versions of a doc when I revise it?

Yes. Docs filed to storage are versioned, so a rewrite branches from a stable base and an earlier version stays recoverable.
